# 2 입력과 단계 기록

- [발표 대본 v1.1](<시공사 미팅 발표 대본 v1.1.md>)은 v2.8 화면과 발표자 노트를 기준으로 작성한 별도 진행용 원고. 영상 재생과 시연실 이동 및 협업 질문을 포함함.

- v2.8은 18장 리드를 영상 관람과 화면 속 놀이 참여가 이어지는 관람객 시점의 문장으로 다듬음.

- v2.7은 18장 리드를 미디어 케이브의 3면 영상과 키즐의 터치·움직임 반응을 설명하는 문장으로 수정함.

- v2.6은 전시 공간 리뉴얼과 도서 캐릭터 체험을 바탕으로 [표지와 마무리 이미지](<../../06_자산/이미지/시공사 미팅 표지/시공사 미팅 표지와 마무리 이미지 작업 기록 v3.0.md>)를 각각 생성함. 2·7·14장 간지의 사진과 배치를 유지하고 배경과 강조색을 따뜻한 차콜, 연한 올리브와 테라코타 계열로 조정함.

- v2.5는 [셀빅 회사 소개서](<../../91_PDF 원본/셀빅 회사 소개서.pdf>) 1, 8, 11, 15, 18, 22, 28, 39쪽과 [주요개발프로젝트 최신본](<../../91_PDF 원본/셀빅_주요개발프로젝트_2026-1104_최신본.pdf>) 1, 7, 15, 20, 24, 29쪽의 표지, 간지와 마무리 지면을 대조함.
- v2.5 1장과 20장에 두 PDF의 표지·마무리 공통 원화와 셀빅 로고를 사용함. 2·7·14장은 동일한 구역 전환 레이아웃과 번호, 제목, 설명 위치를 사용함. 기존 발표에 동봉된 모션 인식 테스트, 스포츠 체험, 전시 공간 사진을 각각 사용함.

- v2.4는 v2.3 사본에서 2장 회사 소개 간지를 삽입하고, 7장과 14장 간지를 함께 다시 구성함. 기존 8~12장에 해당하는 새 9~13장에서 다섯 보조 문구를 삭제하고 남은 대표 사례를 재배치함.
- 구역 제목의 위계와 이미지 활용은 [Gensler Design Forecast](https://www.gensler.com/uploads/document/386/file/df15-designforecast-ar.pdf)와 [Moment Factory 회사 소개](https://momentfactory.com/pages/about)를 참고함.
- v2.4 표지와 마무리는 [실감 전시 개념 이미지 작업 기록](<../../06_자산/이미지/시공사 미팅 표지/시공사 미팅 표지 이미지 작업 기록 v2.0.md>)의 생성 이미지를 사용함. 2장 간지는 v2.3 조직 및 수행 과정 장의 사진을 사용함.

- 회사 현황, 연혁, 기술과 조직은 [주요 개발 프로젝트 최신본](<../../91_PDF 원본/셀빅_주요개발프로젝트_2026-1104_최신본.pdf>) 2~5쪽. 최신 프로젝트의 진행 상태는 6쪽과 상세 지면을 사용. 분야별 제품과 기존 구축 실적은 [셀빅 회사 소개서](<../../05_참고 자료/00_회사자료/셀빅 회사 소개서.md>)와 원본 지면에 대조.
- [텍스트 개요](<../../90_작업 공간/시공사 미팅 발표 전면 개편/1단계 텍스트 개요 v1.0.md>), [슬라이드 구성](<../../90_작업 공간/시공사 미팅 발표 전면 개편/2단계 슬라이드 구성 v1.0.md>), [화면 문구와 노트](<../../90_작업 공간/시공사 미팅 발표 전면 개편/3단계 제목과 본문 v1.0.md>), [디자인 계획](<../../90_작업 공간/시공사 미팅 발표 전면 개편/4단계 디자인 계획 v1.0.md>)을 순서대로 작성함.

# 3 검증 범위

- PowerPoint에서 v2.3 19장 열기와 출력. 본문 7~12장과 14~16장의 하단 요약 띠를 제거하고 사진과 설명 영역을 재배치. 2장 화면은 v2.2와 픽셀 단위로 일치. 패키지 구조와 다시 가져오기 통과.
- 14장 고령과 16장 던파의 사진 및 재생 단추 주소를 검사. 기존 작업에서 고령은 페이지 접속, 던파는 도입부 디코딩을 확인. 이번 개정에서는 주소와 PowerPoint 버튼 동작 설정을 대조.
- 장별 노트에 설명과 근거, 영상 시간 및 주소, 현장과 맞출 시연 내용, 논의용 예비 자료 위치, 감사 인사 기록.
- 회의실 계정에서의 전체 영상 재생과 당일 시연 콘텐츠의 가동은 미확인.

- v2.4는 20장 순서와 삭제 대상 문구, 슬라이드 관계와 기존 영상 링크 주소를 대조함. PowerPoint 화면 출력과 영상 재생은 미확인.

- v2.5는 변경한 5장의 오브젝트 배치 미리보기에서 사진 구도와 제목 적합 여부를 확인함. 구역 레이아웃 1종과 이미지 3종, 나머지 15장 XML 및 관계 보존을 확인함. PowerPoint 화면 출력은 미확인.
