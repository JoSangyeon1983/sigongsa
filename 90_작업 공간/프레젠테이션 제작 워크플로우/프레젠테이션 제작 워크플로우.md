# 1 적용 범위

LLM 위키의 자료를 바탕으로 한국어 발표를 기획하고 수정 가능한 PowerPoint 파일을 만드는 작업 절차. 발표의 목적과 청중에 맞춰 사용할 단계와 실제 결과물을 정함. 이 작업 공간에서 문서와 기본양식을 관리함.

## 1.1 작업 시작

- 누가 듣고 어떤 상황에서 쓰는지, 발표 뒤 청중이 무엇을 이해하거나 논의할지 먼저 확인함. 발표용과 회람용을 함께 만들 때에는 화면에서 필요한 설명과 발표자가 말로 보충할 내용을 구분함.
- 현재 지시와 위키의 출처 제한에 맞춰 이번 발표에 사용할 자료를 고름. 자료 위치, 적용 범위, 확정 여부, 서로 다른 수치나 명칭을 확인함.
- 확정 원고는 Markdown으로 보관함. 내용을 바꿀 때에는 원고를 고치고 영향을 받는 슬라이드와 발표자 노트를 함께 갱신함. 서식과 줄바꿈만 바꾼 경우 원고를 그대로 둠.

# 2 작업 순서

| 순서 | 할 일 | 남기는 결과 |
|---|---|---|
| 1 목적과 근거 | 발표 상황, 청중, 이번에 다룰 범위, 사용할 자료와 상태 확인 | 목적과 근거 목록 |
| 2 텍스트 개요 | 화면 구상에 앞서 발표 흐름과 주장, 필요한 사례를 문장으로 작성 | 텍스트 개요 |
| 3 슬라이드 구성 | 어떤 설명을 한 장에 묶고 어디에서 전환하는지 결정 | 장별 역할과 순서 |
| 4 장별 원고 | 제목, 리드, 본문, 보조 정보, 필요한 그림과 노트 문구를 작성 | 장별 확정 원고 |
| 5 디자인 설계 | 읽는 순서, 정보의 무게, 도형과 사진의 관계 및 공통 요소 결정 | 장별 조판 명세와 필요 시 대표 장표 |
| 6 PPTX 조판 | 마스터와 레이아웃 선택, 원고와 자산을 편집 가능한 개체로 배치 | 작업본 PPTX |
| 7 검수와 전달 | 원고와 실제 화면 대조, 바꾼 장과 영향 범위 확인, 전달 파일 저장 | 최종 PPTX와 실물 검증 기록 |

처음 만드는 발표는 앞 단계의 결과가 다음 판단에 쓰이도록 순서대로 진행함. 작업 단계가 지정됐거나 확정된 원고가 이미 있으면 사용 가능한 결과부터 이어서 진행함. 과정 문서를 각각 남기기로 한 작업은 단계별 파일로 저장하고, 작은 수정은 같은 기록 안에서도 단계와 결과를 알아볼 수 있게 정리함.

- 새 단계 문서와 새 PPTX 및 별도로 저장하는 개정본에는 두 자리 버전을 붙임. [문서 형식의 파일명 기준](<../../00_시스템/01_규정/문서 형식.md#2-문서-제목과-파일명>)

# 3 판단과 검수 시점

- 장별 원고를 확정할 때 사례가 이번 발표의 주장을 뒷받침하는지 확인함. 사실과 제안, 확인이 필요한 내용은 원고에서 식별 가능하게 관리함.
- 새로운 구도가 여러 장에 퍼지기 전에 가장 복잡하거나 중요한 본문을 실제 PowerPoint 화면으로 확인함. 회의 상황에서 읽히는 크기와 정보량, 사진과 설명의 연결을 판단함.
- 최종 파일에서 글과 도형의 편집, 실제 표시, 필요한 링크를 확인함. 수정이 필요하면 결함과 영향을 짚고 해당 범위를 다시 확인함.
