# 1 대표 장표 검수

대표 본문은 가능한 한 실제 문구와 자료를 넣어 PowerPoint로 열어 봄. 원고 표만 읽어서 알 수 없는 화면의 정보 위계, 발표할 때의 시선 이동, 사진의 중요한 부분, 글자 크기를 확인. 비교 자료가 있다면 같은 표시 폭에서 읽는 순서와 내용 밀도, 공통 요소가 유지되는지 대조함.

| 확인 항목 | 판단 기준 |
|---|---|
| 중심 정보 | 장의 제목을 읽은 뒤 실제로 보여 줄 사례나 설명이 바로 보이는가 |
| 정보량과 비중 | 근거가 필요한 만큼 있고 보조 수치나 형식이 본론보다 강하게 보이지 않는가 |
| 요소 관계 | 사진의 위치, 선, 번호, 색이 실제 비교나 흐름과 일치하는가 |
| 공통 디자인 | 제목, 리드, 바닥글과 필요한 대비가 발표 흐름에 맞는가 |

# 2 최종 검수

1. 파일과 확정 원고를 장별로 대조함. 장 순서, 확정 문구, 수치와 단위, 사례 사진의 대응, 발표자 노트와 실제 링크를 확인함.
2. PowerPoint에서 전 장을 열거나 출력해 잘림, 겹침, 글자 대체, 색 대비, 사진의 잘못된 크롭, 남은 예시 글과 빈 그림 자리를 확인함. 사진 안에 박힌 글자와 출처가 다른 사진도 해당 범위에서 봄.
3. 일반 보기에서 대표 장의 제목, 텍스트와 도형을 선택해 편집 가능 여부를 확인함. 마스터와 새 슬라이드 동작이 이번 산출물의 요구 사항이면 새 장을 추가해 제목 자리, 바닥글과 페이지 번호를 확인함.
4. 링크가 있을 때 실제 대상과 파일 속 주소를 대조함. 네트워크와 권한이 있는 환경에서는 실제 발표 계정으로 링크 열기와 영상 재생도 점검하고, 확인 범위를 서로 구분하여 기록함.
5. 사실, 필수 내용, 시각 구조 또는 동작의 문제가 있으면 원고나 슬라이드의 해당 부분과 연결된 장을 고침. 취향상 제안은 전달 효과에 영향이 있는지 판단함. 오탈자와 누락은 최종 화면 확인에서 정리함.

대외 전달용인 경우 현재 요청에 맞춰 고객과 제품 명칭, 사진과 연락처의 공개 범위, 숨은 노트와 이미지 자르기 바깥의 원본 보존 여부 등 실제로 파일에 포함되는 정보를 확인함.

# 3 저장과 인계

- 현행 발표의 편집 정본을 명확히 함. 원고나 디자인 명세를 수정했다면 적용한 PPTX 파일과 기준 시점을 함께 기록함.
- 최종 파일을 PowerPoint로 다시 열고 장수, 장 순서와 표시 상태를 확인함. 작업 후보와 전달본을 구분하고, 이미 사용자가 편집한 파일은 변경 내용을 대조한 뒤 처리함.
- 별도 발표용 산출물은 위키의 산출물 규정에 따라 관리함. 작업 공간에서만 쓰는 기본양식과 시안은 해당 작업 폴더에 둠.
- 검증 기록에는 문서 경로, 확인한 실제 화면과 동작, 해결한 결함 및 미확인 조건을 적음. 원고나 PPTX 자체의 확인과 실제 발표 환경의 재생 및 가독성 점검을 구분함.
