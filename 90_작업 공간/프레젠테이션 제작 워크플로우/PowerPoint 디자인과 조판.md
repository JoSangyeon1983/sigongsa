# 1 조판 전에 장의 구도를 정함

각 장에서 먼저 읽힐 제목과 리드, 그 내용의 근거, 함께 필요하지만 비중이 낮은 정보를 구분함. 근거가 무엇을 보여 주는지에 맞춰 사진 크롭, 카드와 표의 크기, 구분선, 설명 위치를 정함. 중요도가 같은 것은 읽는 조건을 맞추고, 중요도가 다르면 위치나 크기를 다르게 배정함.

| 정보 관계 | 조판에 적용할 요소 | 확인할 점 |
|---|---|---|
| 대표 사례와 보조 사례 | 대표 사진과 제목, 설명이 붙은 카드, 옆이나 아래의 압축 목록 | 청중이 대표 사례부터 읽고 보조 설명으로 이동하는가 |
| 같은 기준의 비교 | 같은 축의 사진 크기, 행마다 반복되는 기준 이름과 값 | 무엇을 기준으로 두 대상을 비교하는지 바로 보이는가 |
| 단계와 결과 | 입력부터 처리까지 순서 표시, 결과 화면에 필요한 면적 | 화살표가 실제 인과나 순서와 일치하는가 |
| 전체와 상세 | 큰 사진에서 대상을 식별, 필요한 부분의 확대와 기능 설명 | 전체에서 찾은 부분과 확대가 정확히 대응하는가 |
| 결론 또는 질문 | 앞 근거에서 실제로 도출되는 문장, 목적에 따라 분리된 강조 영역 | 핵심을 앞의 설명과 연결해 이해할 수 있는가 |

- 레이아웃 수나 사진 수는 장의 내용에 따라 정함. 본문 공통 머리글, 제목과 리드의 위계, 바깥 정렬을 유지하면서 내부 구도를 바꿈.
- 표지와 구역 전환의 시각 변화는 발표 흐름의 경계를 알리는 데 사용함. 같은 구역의 유사한 사례는 공통 서체와 배경 및 여백을 따라가고, 필요한 시각 변화는 실제 내용 영역에 적용함.
- 반복해서 쓸 구도는 설명량이 충분한 대표 장으로 조립해 봄. 화면에서 필요한 정보가 빠졌는지, 강조 위치가 그 장의 중요도를 따르는지 본 뒤 나머지 장에 적용.

# 2 공통 배치와 서식

## 2.1 크기와 정렬

- 기본양식은 16:9, 13⅓ × 7½인치(960 × 540pt). 좌우 여백 48pt로 본문 사용 폭 약 864pt. 1920 × 1080px로 표시한 셀빅 가이드의 5% 좌우 여백을 같은 비율로 적용함.
- 자유 본문은 제목과 리드, 구분선의 위치를 공통화함. 구분선 아래부터 내용에 맞게 직접 조립. 머리 사진이 필요한 경우 중요도와 가독성을 확인하여 넣음.
- 기본 글꼴은 설치된 Pretendard. 예시의 표지 제목 42pt, 본문 제목 28pt, 리드 15pt. 사례 제목, 기본 설명, 보조 캡션은 정보의 역할에 따라 위계를 정함. 회의 화면에서 읽히지 않으면 묶음을 정리하고 공간을 다시 확보함.

## 2.2 색과 도형

- 제목과 본문은 어두운 글자색을 우선 사용함. 기본양식의 청색 `#00429A`는 위치 식별과 제목 구분, 옅은 청색 `#E7EFFA`는 보조 정보 영역, 요약 강조 색 `#B85C4A`는 요약 표식에 사용함.
- 같은 색이 다른 의미로 바뀌어 혼동을 일으키는지 확인함. 사진 위에 글을 얹을 때에는 배경 밝기와 글자 대비를 확인함.
- 원본 사진은 개별 그림으로 삽입하고 비율을 유지해 PowerPoint의 자르기로 보이는 범위를 맞춤. 색면과 글자, 그림 위 어둡게 하는 층은 별개 개체로 유지함. 장 표기와 장식이 사진 속 증거를 가리지 않는지 확인함.

# 3 PowerPoint 조립

1. [기본양식](<프레젠테이션 기본양식.pptx>) 사본을 열고, 마스터 메뉴 또는 새 슬라이드 메뉴에서 필요한 레이아웃을 선택함.
2. 제목, 리드와 필요한 그림을 배치함. 공통 레이아웃에서 제목과 부제를 받아서 쓰거나 완전 빈 화면에 직접 배치함.
3. 본문 구도는 예시 슬라이드를 복제하거나 선택 창에서 필요한 도형 묶음을 가져와 사용함. 그룹 안의 글을 편집하고, 사진 자리 표식은 제거한 뒤 같은 위치에 개별 그림을 삽입함. 새 맥락에서 사진 속 주제와 설명의 관계를 확인함.
4. 비교 항목과 영상 링크, 도형 연결선은 실제 관계를 반영함. 자동 번호와 공통 바닥글은 자유 본문에서 동작을 확인함. 완전 빈 화면의 추가 도형과 번호는 슬라이드 단위에서 관리함.
5. 실제 화면을 확인해 줄바꿈과 겹침을 해결함. 원고가 변경됐다면 원고와 조판 사본을 먼저 맞추고 [검수와 전달](<PPTX 검수와 전달.md>)로 넘김.

마스터 레이아웃의 배경, 구분선은 마스터 보기에서 편집함. 일반 보기에서 재사용할 카드와 보조 영역은 예시 슬라이드에 개별 도형으로 들어 있음. 기존 Figma의 컴포넌트와 같은 목적을 PowerPoint의 마스터, 자리표시자와 슬라이드 도형으로 나눠 구현함.
