# 1 목적과 자료

- 청중의 역할과 알고 있는 내용, 발표 뒤에 이해할 사항이나 논의할 결정을 적음. 같은 자료라도 소개, 협업 논의, 검토 보고에서 필요한 사례와 설명이 달라짐.
- 후보 자료에서 이번 발표에 해당하는 근거를 고르고 위치를 남김. 사례의 공식 명칭, 수행 범위, 수치의 단위와 기준, 사진의 실제 대상, 영상과 공개 상태를 해당되는 범위에서 확인함.
- 자료마다 값이나 설명이 다르면 근거 위치와 차이를 기록하고 적용할 내용을 결정함. 확인이 필요한 사항은 내부 원고에서 국소적으로 표시함. 청중에게 불확실성 자체를 알려야 하는 경우 화면에 그 상태를 정확히 씀.

| 사용할 내용 | 근거와 위치 | 상태 | 적용 장 또는 확인 사항 |
|---|---|---|---|
| 예시로 소개할 사업의 공식 명칭 | 원자료 이름과 해당 쪽 또는 절 | 확인 | 사례 제목 |
| 비교에서 사용할 수치 | 원자료 이름, 단위와 기준일 | 확인 필요 | 기준일의 적용 범위 대조 |

# 2 개요와 슬라이드 구성

## 2.1 텍스트 개요

1. 발표에서 설명할 흐름을 문단으로 적음. 도입에서 논의 목적을 열고, 본론에서 그 목적에 필요한 근거와 사례를 설명한 다음, 질문이나 결정 사항으로 연결함.
2. 주제마다 청중이 이해해야 하는 것과 실제 근거를 짝지음. 제목만 훑어도 장 사이의 흐름을 따라갈 수 있는지 확인함.
3. 사진, 영상과 보조 사례의 역할을 기록함. 실제 공간의 크기나 작동 방식을 설명하는 증거, 사례 식별, 구역 전환 등 역할에 따라 배치 위치가 달라짐.

## 2.2 슬라이드 구성표

| 장 | 역할 | 먼저 전달할 내용 | 함께 보여 줄 근거 | 다음 장과 연결 |
|---|---|---|---|---|
| S01 | 도입 | 이번에 논의할 목적 | 필요한 경우 대표 이미지 | 이후 읽을 두 안건 |
| S02 | 사례 설명 | 이 장에서 이해할 핵심 | 대표 사례, 보조 사례와 필요한 조건 | 다음 사례 또는 질문 |

위 표를 실제 순서에 맞게 작성함. 각 장의 메시지를 뒷받침하는 사례, 비교 항목이나 과정을 충분히 담고 읽는 순서로 묶음. 설명이 갈라지거나 필요한 가독성을 확보하기 어려운 경우 구도를 바꾸거나 장을 나눔. 표지, 구역 전환과 마무리 장은 발표 흐름에 필요한 경우 사용함.

# 3 장별 원고

## 3.1 복사해서 쓰는 형식

```markdown
## S02 체험 공간의 주요 구역

- 장의 역할
- 청중이 먼저 이해할 내용
- 화면 제목
- 리드
- 중심 본문
  - 정보 묶음별 소제목과 표시할 문구
  - 사진, 도표 또는 영상의 역할과 정확한 파일 경로
- 보조 정보
  - 적용 조건, 추가 사례 또는 필요한 비교 항목
- 마지막에 읽힐 결론 또는 질문
- 발표자 노트
  - 말로 보충하는 설명, 자료 위치와 영상 주소
- 남은 확인 사항
```

- 화면 제목, 리드, 카드 등의 문구는 실제 표시할 말로 작성함. 장에 필요한 정보는 제목, 본문, 그림 또는 발표자 노트 중 알맞은 위치에 둠.
- 수치는 청중이 규모, 비교 또는 조건을 판단하는 데 쓰일 때 크게 배치할 내용으로 지정함. 제작 편수나 형식처럼 사례를 보충하는 항목은 전체 사례를 설명하는 비중에 맞춰 둠.
- 사진 설명과 출처를 청중에게 보여 줄지는 자료 식별과 발표 목적에 따라 결정함. 필요한 출처는 노트나 관리 기록에서 찾을 수 있게 함. 미정 문구, 버전, 내부 검수 상태의 표시 여부는 실제 논의에 필요한지를 기준으로 판단함.

## 3.2 원고에서 화면으로 넘기는 기준

예를 들어 체험 공간의 구역을 설명하는 장에서는 먼저 구역별 행동과 전환을 작성함. 대표 구역은 사례 카드, 설비와 가시성 같은 공통 조건은 보조 목록, 청중에게 남길 공간 설계 관점은 요약 문장으로 배치할 수 있음. 이렇게 같은 장 안의 각 묶음이 맡는 역할을 원고에서 확인한 뒤 크기를 결정함. [사례와 보조 정보의 PPTX 예시](<프레젠테이션 기본양식.pptx>)

- 원고의 확정 범위와 미확인 항목을 명시하여 [디자인과 조판](<PowerPoint 디자인과 조판.md>)에 넘김.
- 조판에서 문구를 바꿀 필요가 생기면 실제 수정안을 원고에 반영하고 해당 장의 화면과 노트를 다시 대조함.
