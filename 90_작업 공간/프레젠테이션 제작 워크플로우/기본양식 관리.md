# 1 파일과 용도

- [프레젠테이션 기본양식 PPTX](<프레젠테이션 기본양식.pptx>). [워크플로우](<프레젠테이션 제작 워크플로우.md>)에서 실제 PowerPoint 조판을 시작할 때 사본으로 사용함.
- 마스터 1개, 사용자 지정 레이아웃 4개, 예시 슬라이드 5장. 16:9, Pretendard 사용. 그림 자리와 설명 문구는 구도를 시연하는 예시용 개체.
- 편집 정본은 이 PPTX. 다른 프로젝트에 쓰는 발표 파일은 별도 이름으로 저장하고 발표마다 필요한 원고와 자료를 적용함.

# 2 레이아웃과 샘플

| 레이아웃 | 포함된 요소 | 활용 |
|---|---|---|
| 01 표지 | 배경, 제목과 부제, 그림 자리표시자 | 발표 제목과 대표 그림 |
| 02 구역 전환 | 전환 배경, 제목과 설명, 그림 자리표시자 | 실제 주제가 바뀌는 곳 |
| 03 자유 본문 | 제목과 리드, 공통 정렬과 구분선, 바닥글, 자동 번호 | 사례, 비교와 같은 주제별 본문 |
| 04 완전 빈 화면 | 빈 배치 | 요소 위치를 직접 결정하는 본문 |

- 예시 1~2는 표지와 구역 전환. 3장은 사진과 설명이 붙은 사례 카드, 보조 목록, 운영 정보 띠와 요약. 4장은 같은 기준으로 나란히 비교. 5장은 빈 화면 위에 조립한 입력, 처리, 결과 예시.
- 사례 카드, 단계와 요약 띠는 일반 보기에서 선택하고 복제할 수 있는 그룹. 그룹 안에서 글을 직접 고치고, 그림 자리 표시 도형을 교체해 쓸 수 있음. 자유 본문의 공통 요소와 표지 배경은 슬라이드 마스터에서 관리.
- 새 장에는 해당 레이아웃을 선택하고 제목과 그림 자리표시자를 채움. 예시를 복제했다면 조립 예시용 그림 자리와 문구를 실제 자료로 교체함. 자유 본문의 `발표 자료` 문구는 PowerPoint의 머리글/바닥글 메뉴에서 프로젝트에 맞춰 바꿈.

# 3 적용 근거와 검증

- 사용자 지정 셀빅 회사 소개서 제작 가이드의 디자인 시스템과 조판 예시를 확인하여 제목 위계, 가로 여백, 본문 정보 묶음과 하단 요약에 적용. 예시 소재와 레이아웃 수는 이 위키의 새 기본양식용으로 선택함.
- PowerPoint에서 예시 5장 렌더 확인. 4종에서 새로 만든 장의 제목 및 그림 자리표시자와 완전 빈 화면을 대조. 자유 본문의 자동 번호가 장을 앞에 추가했을 때 8에서 9로 갱신되는 것을 확인함.
- 사례 예시를 복제해 그룹 안의 제목과 그룹 위치를 바꾸고 원본 예시가 그대로인 것을 확인함. PPTX 패키지 검사와 다시 가져오기 통과. SHA-256 `fb11d634631cedfeeb62f0a1b4eda0a15f8aaf433cb94e7ff5430b6f1e7ecaf2`.
- 회의별 사진, 영상과 링크는 실제 원고로 채운 뒤 [검수와 전달 절차](<PPTX 검수와 전달.md>)에 따라 확인함.
