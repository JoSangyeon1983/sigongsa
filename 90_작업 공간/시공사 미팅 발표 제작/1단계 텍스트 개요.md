# 1 목적과 청중

시공사 첫 미팅에서 셀빅이 어떤 회사이며 공간과 디지털 콘텐츠를 실제로 어떻게 기획하고 구축하는지 보여 줌. 출판사 공간 리뉴얼과 도서 IP 기반 캐릭터 활용의 두 가지 논의로 연결함. 대회의실에서 대표 사례를 본 뒤 시연실에서 미디어 케이브 3면 영상과 키즐을 중심으로 살펴보는 진행을 기준으로 함.

# 2 발표 흐름

1. 셀빅의 주요 사업 분야를 짚고, 기획, 콘텐츠, 소프트웨어와 장비, 현장 설치와 운영 지원으로 이어지는 수행 범위를 설명.
2. 고령 대가야생활촌 사례에서 전시 주제를 공간과 디지털 매체에 담은 모습을 소개. 이어 EBS 유성 AI 놀터에서 방송과 지역 캐릭터가 어린이 놀이 경험으로 이어진 사례를 보여 줌.
3. 던파 페스티벌에서 하나의 IP를 미디어월, 그림 인식, 포토부스로 적용한 차이를 설명. 셀빅의 체험존과 미디어월 기획, 개발 및 설치와 관람객 결과물을 대응시킴.
4. 미디어 케이브에서 3면 영상이 공간에 이어지는 방식과 키즐에서 참여자의 행동에 화면이 반응하는 방식을 소개. 재생할 영상과 키즐 콘텐츠는 현장 준비에 맞춤.
5. 공간 리뉴얼과 도서 IP 활용에서 다룰 항목을 체크리스트로 제시. 우선순위와 실제 적용 범위를 회의에서 논의함.
6. 참석에 대한 감사 인사로 마무리함.

# 3 입력과 범위

- 회의 흐름과 두 안건은 [시공사 협업 개요](<../../01_프로젝트/시공사 협업 개요.md>) 2~3절, 회사와 사례 사실은 [셀빅 회사 소개서](<../../05_참고 자료/00_회사자료/셀빅 회사 소개서.md>)와 원본 PDF의 4, 10, 19, 26~27, 32, 37쪽을 사용. 현장 시연의 중심 콘텐츠와 논의 체크리스트에는 2026-11-19 사용자 보완 적용.
- 대표 사례와 시연 후보의 순서는 [시공사 미팅에서 보여줄 자료](<../시공사 미팅 자료 선별/시공사 미팅에서 보여줄 자료.md>)를 검토하고 사용자가 승인한 제작 계획을 적용.
- 꿈이담, 아이들나라 그림책, 해별이와 친구들은 해당 질문이 나올 때 참고할 자료로 원본 위치를 유지.
