# 1 공통 구조

16:9 새 기본양식의 표지와 자유 본문을 사용. 본문은 제목과 리드, 좌우 여백 5%, 위아래 구분, 하단 회사명과 자동 쪽 번호를 유지. 소분류 색과 내용의 밀도는 본문 영역에서 조절함. 사진과 색면, 텍스트, 영상 링크는 각각 PowerPoint 개체로 유지.

셀빅 회사 소개서 4, 10, 26, 27쪽에서 정보가 제목과 리드, 사례 또는 과정, 보조 설명으로 나뉘는 방식과 각 영역의 거리 및 비중을 참고. 내용은 [3단계 제목과 본문](<3단계 제목과 본문.md>)의 문구 적용.

# 2 장별 조판

| 장 | 먼저 보이는 요소 | 보조 정보의 위치와 방식 |
|---|---|---|
| 01 | 셀빅 소개서 표지 연출 이미지 위 큰 두 줄 제목 | 왼쪽 남색 그라데이션으로 제목 자리 확보. 부제와 회사명만 같은 축으로 정렬 |
| 02 | 기획, 콘텐츠, 시스템과 설치, 운영 지원의 4개 수행 영역 | 사업 분야 6개는 상단 두 줄로 압축. 아래에는 단계마다 실제 역할을 두 줄씩 설명 |
| 03 | 벽과 바닥으로 이어지는 큰 영상 장면 | 같은 영상의 풍경과 전시물 장면을 오른쪽에 작게 연결. 아래에 전시 설계 관점 |
| 04 | 어린이들이 놀이 화면 주변에 모인 현장 사진 | 오른쪽에 캐릭터가 보이는 디지털 놀이 화면과 설명을 붙여 관람 행동에서 콘텐츠의 관계로 읽히게 함 |
| 05 | 미디어월을 큰 현장 증거로 배치 | 그림 인식과 포토부스는 작은 상단 현장 사진과 하단 결과물로 각각 구성. 수행 띠와 영상 버튼, 요약 사이에 3가지 체험이 읽히게 배치 |
| 06 | 미디어 케이브와 키즐의 체험 이미지 | 두 사진 아래에 시연 내용과 관람 포인트를 배치. 케이브 사진은 자료 예시로 표시하고 키즐은 참가자의 움직임을 보여 주는 사진 사용 |
| 07 | 공간 리뉴얼과 도서 IP 활용의 두 열 | 항목 3개씩 빈 체크 상자와 함께 배치. 사진과 질문 문구를 빼고 논의 항목을 바로 읽게 구성 |
| 08 | `감사합니다` 문구 | 표지의 연출 이미지와 왼쪽 남색 그라데이션, 로고를 적용 |

# 3 대표 장표 확인

- 05장만 먼저 조립해 PowerPoint에서 1280 × 720으로 내보내고 같은 너비의 소개서 27쪽과 맞춰 봄.
- 미디어월, 그림 인식, 포토부스를 서로 다른 참여 방식으로 읽을 수 있는지 확인. 글자가 행동과 결과를 설명하고 사진이 그 설명 옆에서 증거로 작동하는지 확인.
- 대표 장표 확인 뒤 나머지 본문과 마무리를 조립하고 전체를 실제 PowerPoint에서 확인. 영상 링크 주소 비교와 실제 접속 및 재생 확인 범위를 구분.
