# 1 목적

시공사에 셀빅이 어떤 회사이고 어떤 기술과 사업을 보유하는지 먼저 소개. 그다음 출판사 공간 리뉴얼과 도서 IP 활용에 바로 연결되는 사례를 보여 줌. 회사 대 회사 소개와 이번 회의의 구체적인 논의를 하나의 흐름으로 연결.

# 2 설명 흐름

1. 회사 개요에서 회사의 정체성과 규모를 소개한 뒤, 연혁에서 체감형 콘텐츠부터 실감 공간과 공공 시스템, AI 융합으로 이어진 흐름을 보여 줌.
2. 8개 기술 영역을 구현 방식과 적용 사례로 설명. 이어 조직과 수행 과정에서 누가 기획, 콘텐츠, SW, HW, 설치와 운영을 맡는지 설명.
3. 전체 사업은 실감형 공간과 전시, 공공 시스템 구축, 스포츠 XR과 파크골프, 키즈 에듀테크, AI 체험과 IP 행사, AI 콘텐츠 제작 순. 분야마다 무엇을 제공하고 어느 현장에서 쓰였는지 실제 콘텐츠와 사례로 보여 줌.
4. 전체 사업을 본 뒤 ‘전시 공간과 체험 콘텐츠’ 구간에서 고령 대가야생활촌, EBS 유성 AI 놀터, 던파 페스티벌, 미디어 케이브와 키즐을 소개. 공간 영상, 상설 캐릭터 놀이, 행사 IP 적용, 3면 영상과 참여형 놀이를 보여 줌.
5. 공간 리뉴얼과 도서 IP 활용의 체크리스트를 제시한 뒤 감사 인사로 마무리.

# 3 근거와 상태

- 회사 현황, 연혁, 기술, 조직은 [11월 4일 주요 개발 프로젝트 최신본](<../../91_PDF 원본/셀빅_주요개발프로젝트_2026-1104_최신본.pdf>) 2~5쪽. 주요 프로젝트 이름과 진행 상태는 같은 PDF 6쪽과 해당 프로젝트 지면.
- 전체 사업 분류와 대표 제공 내용 및 기존 구축 사례는 [셀빅 회사 소개서](<../../91_PDF 원본/셀빅 회사 소개서.pdf>) 5~31쪽. 두 PDF의 수치나 상태가 다르면 해당 사실을 직접 다루는 원문과 기준 시점을 기록.
- 맞춤 소개와 시연은 [시공사 협업 개요](<../../01_프로젝트/시공사 협업 개요.md>)와 사용자가 승인한 구성 및 시연 보완을 적용. 특정 시연 콘텐츠의 현장 가동, 대상 공간과 도서 IP는 별도 확인.
