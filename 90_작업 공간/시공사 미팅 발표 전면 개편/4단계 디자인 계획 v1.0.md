# 1 공통 체계

16:9 기본양식으로 제목과 리드, 바깥 좌우 5% 정렬, 자동 쪽 번호를 유지. 회사 소개는 파랑, 전체 사업의 6개 분야는 해당 분야 표식, 시공사 맞춤 소개는 동일한 제목 체계 안에서 별도 머리글로 식별. 표지와 마지막 장은 같은 회사 이미지와 로고를 사용.

# 2 장별 구도

| 장 | 본문 조직 |
|---|---|
| 02 | 왼쪽 회사 정보표, 오른쪽 규모와 사업 지표, 아래에 회사의 사업 방향 |
| 03 | 5개 시기별 세로 연혁과 당시 자료 사진 띠 |
| 04 | 기술 8종을 네 갈래로 묶은 표. 기술명, 구현 기술, 대표 제품과 사례를 같은 행에 정렬 |
| 05 | 위쪽의 조직과 부서, 아래쪽의 6단계 수행 과정. 역할과 실제 작업 이미지를 대응 |
| 06 | 대표 사례 2행 2열과 오른쪽 수행 범위. 사진과 설명 및 요약의 비중을 구분 |
| 07 | 구축 사례와 공동 개발을 구분한 사례 카드와 공공 시스템 제공 범위 |
| 08 | 스포츠 제품과 적용 사례를 비교할 수 있게 사진과 설치 및 운영 정보 제시 |
| 09 | 키즐을 크게 소개하고, 샌드크래프트와 그림 인식의 작동 및 제품군을 보조 패널로 제시 |
| 10 | IP 적용 사례를 왼쪽에, 개발 중인 Closer를 오른쪽에 배치해 성격을 구분 |
| 11 | 제작 스튜디오, 홍보 공동 제안, 공간 시각화 서비스를 사례와 함께 배치 |
| 12~14 | 공간 연출의 큰 장면과 보조 장면, 놀이 현장과 디지털 화면, 행사 체험과 결과물 등 사례에 맞춘 본문 |
| 15 | 3면 영상과 참여형 디지털 놀이를 나란히 배치. 각 사진 아래 관람 시야와 화면 반응 설명 |
| 16 | 공간 리뉴얼과 도서 IP 활용 논의 체크리스트 |
| 17 | 표지 배경과 로고 위 감사 인사 |

- 12~15장은 공통 머리글 ‘전시 공간과 체험 콘텐츠’를 같은 위치에 배치. 장별 부제와 이미지 구도는 각 사례의 성격을 나타냄.

# 3 대표 장 검증

- 06장 전체 사업 사례와 14장 시공사 맞춤 사례를 먼저 PowerPoint에서 열고, 소개서 10쪽과 27쪽을 같은 폭으로 대조. 정보 층위와 사진을 보는 순서, 줄바꿈 및 편집 개체 확인.
- 최신본은 이미지형 PDF. 회사 소개 장표의 글과 구조를 PowerPoint에서 직접 조립. 원본 지면의 장면 사진 일부는 실제 자산으로 배치.
- 최종 17장의 출력, 날짜와 진행 상태, 2개 영상 버튼과 노트를 확인.
