# 2 설명 깊이와 전환

- 06~11장은 회사가 제공하는 전체 사업을 소개. 대표 제품이나 사례에 설명을 붙여 각 분야의 범위를 알 수 있게 함.
- 12~15장은 전시 공간과 체험 콘텐츠를 실제 사진과 작동 방식 중심으로 설명. 12장과 14장은 장표에 연결된 현장 영상 활용 가능.
- 16장은 질문형 문구 없이 논의 항목을 표시. 17장은 표지와 짝을 이루는 마무리.
