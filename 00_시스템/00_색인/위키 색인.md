# 1 이용 안내

- 셀빅과 시공사의 협업 검토를 위한 LLM Wiki의 운영 문서와 자료 진입점. 협업은 미확정 상태.
- 프로젝트에는 시공사 협업 개요를 등록하고 회사 소개자료 2종을 보관함. 중국 출장 관련 자료는 포함하지 않음.
- 자료의 등록과 복사를 기획 근거 채택이나 새로운 배포 승인으로 취급하지 않음.

- `.obsidian`에는 기본 보관함 설정과 헤더 표시용 CSS 보관. 개인 세션 상태 제외.

# 6 등록과 갱신

- 새 문서는 역할별 위치와 상태를 확인한 뒤 색인에 연결함.
- 별도 사용과 전달용 파일은 산출물 색인에 관리 기록과 함께 등록함.
- 파일 변경은 월별 로그에 기록하고 경로 변경 시 본문과 메타데이터 연결을 함께 점검함.
