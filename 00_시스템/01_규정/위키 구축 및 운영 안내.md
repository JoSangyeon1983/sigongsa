# 3 운영 시작

## 3.1 문서 작성

1. [위키 색인](<../00_색인/위키 색인.md>)에서 자료와 역할별 위치 확인함.
2. 첫 실질적인 작업 전에 [작성 규칙](<작성 규칙.md>), [문서 형식](<문서 형식.md>)과 [작업 절차](<작업 절차.md>) 확인함.
3. 회의록이나 이미지 작업에는 해당 작업별 규칙 추가 적용함. 문서의 출처, 검토와 승인 상태 구분함.
4. 헤더 번호와 링크, 실제 파일 및 출처 대조 후 관련 색인과 월별 로그 갱신함.
5. 하위 폴더는 실제 보관할 내용이 있을 때 생성함. Obsidian에서는 현재 위키 루트를 보관함으로 열어 사용함.

## 3.2 유지 관리

- 파일 이름이나 위치를 바꾸면 본문, 메타데이터와 색인 링크를 함께 갱신함.
- 새 자료는 역할에 맞게 등록하고, 기획에 사용할 내용은 채택 결정과 적용 범위를 확인하여 `02_기획 근거`에 먼저 반영함.
- 작업 결과는 해당 월의 로그에 기록함. 사용자 버전 값을 임의로 부여하거나 증가시키지 않음.
- 보관소는 Git 추적 대상에서 제외하고 보관소 밖에서 내부 자료로 연결하는 링크를 만들지 않음.
