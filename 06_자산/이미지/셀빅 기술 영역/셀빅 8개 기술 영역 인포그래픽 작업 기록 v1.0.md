# 1 용도와 근거

- 시공사 미팅 발표 v2.1의 4장 본문 표를 대체할 별도 PNG. 전체 제목 생략, 가로세로 2:1, 배경 순백색 `#FFFFFF`.
- 4장의 기술 영역, 구현 기술, 적용 제품과 사례를 유지. 4개 갈래 아래 기술 8종을 묶고 영역마다 구현과 적용 사례를 짝지어 표시.
- 입력은 [발표 v2.1](<../../../08_산출물/시공사 미팅 회사 및 콘텐츠 소개/시공사 미팅 셀빅 회사 및 콘텐츠 소개 v2.1.pptx>) 4장과 [장별 원고의 기술과 적용](<../../../90_작업 공간/시공사 미팅 발표 전면 개편/3단계 제목과 본문 v1.0.md#12-기술과-적용>).
- 도식의 핵심 메시지. 체감 인터랙션, 실감 공간, AI, 시스템의 기술 갈래와 실제 적용 사례의 대응.

# 2 생성 설정과 프롬프트

- 시도 01. 내장 이미지 생성 도구로 기술별 픽토그램 8종을 한 장에 생성. 화면비 2:1 요청, 투명 배경 거짓. 생성 파일 1774 × 887 PNG. 호출 반환에서 모델 미확인.
- 생성 시 지정 문자열 없음. 한국어 원고와 적용 사례는 조판에서 정확한 문자열로 입력해 최종 PNG에 표시.

# 3 조판과 정보 구성

- 좌우 두 열에 기술 영역과 구현, 적용 제품과 사례의 관계를 배치. 체감 인터랙션 2개와 AI 2개를 왼쪽에 배치. 실감 공간 3개와 시스템 1개를 오른쪽에 배치. 기술별 픽토그램, 구현 설명과 적용 사례의 순서.
- 네 갈래에 서로 다른 색을 지정. 같은 행의 화살표는 해당 기술의 적용 관계. 기술과 기술 사이의 선후 관계 표시는 생략.
- 원본의 세 가운뎃점을 문맥에 맞게 접속 표현으로 표기. 화면에 표시할 열 안내는 양쪽에 각 1회 배정. 4장 기존 제목은 PNG에서 생략.
- 실제 픽토그램을 각 칸에서 분리해 조판하고, 기술명, 구현, 사례를 Pretendard로 직접 렌더링. Chromium에서 순백색 배경의 가로 2000px, 세로 1000px PNG 캡처.
